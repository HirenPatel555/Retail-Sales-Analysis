# SQL Retail Sales Analysis

A SQL project focused on analyzing retail sales data using **MySQL**.

### Analysis Includes

* Data exploration and cleaning
* Sales analysis by category
* Customer analysis
* Gender-wise transaction analysis
* Monthly sales analysis
* Top customers by total sales
* Sales analysis by time shifts

### Tools

* MySQL
* SQL

### Key SQL Concepts

`SELECT` · `WHERE` · `GROUP BY` · `ORDER BY` · `JOIN` · `Aggregate Functions` · `CTE` · `CASE` · `Window Functions`
